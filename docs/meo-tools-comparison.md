# MEO対策ツール比較と導入タイミング

案件数がまだ少ない立ち上げ初期は、有料ツールなしでも運用できます。
このドキュメントは「いつ、どのツールに投資すべきか」の判断材料としてご利用ください。

## 導入タイミングの目安

| 担当店舗数 | 推奨する運用 |
|---|---|
| 1〜5店舗 | すべて無料代替（スプレッドシート＋手動確認）で十分 |
| 6〜15店舗 | 順位計測ツールのみ有料化を検討（手動確認の工数が増えるため） |
| 16店舗以上 | GBP一括管理ツール・CRMの有料化を検討 |

## カテゴリ別詳細

### 1. MEO順位計測ツール
- **有料例**: GMBrank、MEOチェキ、ラッコ順位チェッカー、Rank Tracker
- **費用感**: 月額3,000円〜（店舗数課金が多い）
- **無料代替**: `tools/junni-keisoku-sheet.xlsx`（自作済み。シークレットウィンドウ＋手動検索の結果を入力すると、店舗別の平均順位を自動集計・グラフ化）
- **判断基準**: 対象キーワード×店舗数が増えて手動確認が週1時間を超えたら有料化を検討。自動スクレイピングでの代替はGoogle利用規約違反のリスクがあるため非推奨（有料化するなら公式API準拠のツールを選ぶ）

### 2. GBP一括管理・投稿予約
- **有料例**: Storefront、Yext、ChatKastle
- **費用感**: 月額数千〜数万円（多店舗向け）
- **無料代替**: `tools/toukou-calendar.xlsx`（自作済み。複数店舗の投稿予定・進捗を管理し、期限超過を自動アラート）を使い、実際の投稿はGBP管理画面から手動で行う
- **判断基準**: 同時に管理する店舗が10を超え、投稿の抜け漏れが発生し始めたら検討

### 3. 顧客管理（CRM）
- **有料例**: HubSpot（無料枠あり）、kintone、Salesforce
- **費用感**: 無料枠〜月額数千円
- **無料代替**: `tools/crm-kanri-sheet.xlsx`（自作済み。契約終了日が近い顧客を自動で色分け表示し、契約中の合計月額も自動集計）
- **判断基準**: 案件が20件を超え、対応漏れが起きたら検討。HubSpotは無料プランの範囲でも十分実用的

### 4. 会計・請求
- **有料例**: freee、マネーフォワードクラウド
- **費用感**: 無料お試し後、月額1,000円台〜
- **無料代替**: `tools/seikyuusho-generator.xlsx`（自作済み。数量・単価を入力すると消費税・合計まで自動計算）
- **判断基準**: 確定申告の時期、または月間請求件数が10件を超えたら有料化を検討

### 5. ビジネス電話番号
- **有料例**: 050 plus、Smartalk等のIP電話
- **費用感**: 月額300〜700円
- **無料代替**: 個人携帯番号で運用
- **判断基準**: 名刺や契約書に固定の事業用番号を載せたくなったタイミングで導入

### 6. 電子契約
- **有料例**: クラウドサイン、GMOサイン
- **費用感**: 無料枠あり（月数件まで）、以降は件数課金
- **無料代替**: `docs/templates/keiyaku-gyomuitaku.md` をPDF化し、印刷・押印または簡易電子サインで運用
- **判断基準**: 月の契約締結件数が無料枠を超えたら有料化

### 7. LP・サイト運用
- **有料例**: ペライチ、STUDIO
- **費用感**: 月額1,000〜3,000円
- **無料代替**: 本リポジトリの `lp/index.html` を GitHub Pages / Cloudflare Pages 等の無料枠でホスティング
- **判断基準**: フォームの自動返信やCMS的な更新頻度が上がってきたら検討

## 結論

- 初期費用ゼロ・当日開始を優先するなら、**すべて無料代替で開始**し、案件が増えたカテゴリから順に有料化するのが合理的です。
- 唯一「早めに検討する価値がある」のは順位計測ツールで、手動確認の工数が最も早く積み上がるためです。
