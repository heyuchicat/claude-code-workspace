# Android スマートフォンから PC 経由で SMS を遠隔送信する方法

PC（Windows/Mac/Linux）から Android スマホの SMS 送信機能を遠隔で使うための、代表的な 3 つの方法をまとめています。目的や技術レベルに応じて選んでください。

---

## 1. 方法の選び方

| 方法 | 難易度 | 追加アプリ | 自動化・スクリプト連携 | ネットワーク要件 |
|---|---|---|---|---|
| [方法A: Google メッセージ（ウェブ版）](#2-方法a-google-メッセージ-ウェブ版推奨初心者向け) | 低 | 不要（プリインストール済のことが多い） | 不可（手動操作のみ） | 同一 Wi-Fi 不要（インターネット経由） |
| [方法B: Termux + SSH](#3-方法b-termux--ssh開発者コマンドライン向け) | 中〜高 | Termux, Termux:API | 可（コマンド1発で送信、スクリプト化可） | 同一 Wi-Fi、または外部公開設定 |
| [方法C: Tasker + HTTP連携](#4-方法c-tasker--httpサーバー自動化アプリ向け) | 中 | Tasker（有料） | 可（Webhook/HTTPリクエストで送信） | 同一 Wi-Fi、または外部公開設定 |

- **手動で数通だけ送りたい** → 方法A
- **PC のスクリプトやコマンドから自動送信したい（エンジニア向け）** → 方法B
- **アプリ連携・自動化フローの一部に組み込みたい（非エンジニア寄り）** → 方法C

> **注意（送信の仕組みについて）:** これらの方法はいずれも、SMS の実際の送信処理は Android スマホ本体（＝契約している携帯電話回線）が行います。PC 単体で SMS を送信することはできません。PC はスマホに「この宛先にこの内容を送って」と指示を送るだけです。したがってスマホの電源が入っており、ネットワーク（Wi-Fi またはモバイル通信）に接続されている必要があります。

---

## 2. 方法A: Google メッセージ（ウェブ版）【推奨・初心者向け】

Android 標準の SMS アプリ「メッセージ（旧 Android Messages）」の Web 版機能を使う、最も簡単で公式な方法です。

### 前提条件
- スマホに Google の「メッセージ」アプリが入っていること（多くの Android 端末に標準搭載）
- スマホと PC が両方インターネットに接続されていること（同一 Wi-Fi でなくても可）

### 設定手順
1. スマホで「メッセージ」アプリを開く。
2. 右上のアカウントアイコン（またはメニュー）→ **「デバイスの登録」** または **「メッセージ (ウェブ版)」** を選択。
3. PC のブラウザで `messages.google.com/web` を開く。
4. スマホ側の QR コードスキャン画面で、PC 画面に表示された QR コードを読み取る。
5. ペアリングが完了すると、PC のブラウザ上で SMS の送受信ができるようになる。

### 使い方
- PC のブラウザ画面から宛先を選択し、メッセージを入力して送信するだけ。
- 一度ペアリングすれば、次回以降は `messages.google.com/web` にアクセスするだけで利用可能（ブラウザの Cookie を消さない限り）。

### メリット・デメリット
- ○ 追加アプリ不要、無料、公式機能で安全
- ○ 画像・グループ送信なども可能
- × 自動化（スクリプトからの送信）はできない。あくまで手動操作用
- × スマホが完全にオフライン（電源オフ・機内モード）だと送受信できない

## 3. 方法B: Termux + SSH（開発者・コマンドライン向け）

スマホ上で Linux 環境を動かす「Termux」アプリと、SMS 操作用の拡張パッケージ「Termux:API」を使い、PC から SSH でスマホに接続してコマンドで SMS を送信する方法です。

### 前提条件
- スマホに [Termux](https://f-droid.org/packages/com.termux/)（**F-Droid 版を推奨**。Google Play 版は機能制限あり）と [Termux:API](https://f-droid.org/packages/com.termux.api/) をインストール
- PC とスマホが同一 Wi-Fi ネットワーク上にある（または外部からアクセスできるようポート開放/VPN設定済み）

### 設定手順

**スマホ側（Termux アプリ内で実行）**
```bash
# パッケージ更新とインストール
pkg update && pkg upgrade
pkg install openssh termux-api

# SSH サーバーを起動
sshd

# Termux のユーザー名とパスワードを確認・設定
whoami
passwd
```
- Termux は デフォルトで SSH ポート `8022` を使用します。
- Android 側で「Termux:API」との連携を許可するダイアログが出たら許可してください。
- スマホの SMS 権限（送信）を Termux:API に許可しておく（設定 → アプリ → Termux:API → 権限 → SMS）。

**スマホの IP アドレスを確認**
```bash
ifconfig | grep 'inet '
# もしくは
ip a
```

**PC 側から SSH 接続**
```bash
ssh -p 8022 <ユーザー名>@<スマホのIPアドレス>
```

### SMS 送信コマンド
Termux:API には SMS 送信用コマンド `termux-sms-send` があります。SSH 接続後（またはワンライナーで直接）実行できます。

```bash
# スマホにSSH接続した状態で実行
termux-sms-send -n "090XXXXXXXX" "PCから遠隔送信するテストメッセージです"
```

PC から SSH のワンライナーとして直接実行することも可能です:
```bash
ssh -p 8022 <ユーザー名>@<スマホのIPアドレス> \
  'termux-sms-send -n "090XXXXXXXX" "PCから遠隔送信するテストメッセージです"'
```

複数宛先へ送る場合は `-n` を複数回指定します:
```bash
termux-sms-send -n "090XXXXXXXX" -n "080YYYYYYYY" "一斉送信メッセージ"
```

### メリット・デメリット
- ○ PC のシェルスクリプトや cron、外部システムから完全に自動送信できる
- ○ 無料・オープンソース
- × 初期セットアップがやや複雑（Termux, SSH, 権限設定）
- × スマホ画面をロックすると Termux がバックグラウンドで制限される機種があるため、「バッテリー最適化の対象外」に設定しておくことを推奨
- × 外部（インターネット越し）から使う場合は、SSH のセキュリティ対策（公開鍵認証、ポート開放範囲の限定など）が必須

## 4. 方法C: Tasker + HTTP連携（自動化アプリ向け）

Android の自動化アプリ「Tasker」（有料）を使い、PC やサーバーから HTTP リクエストを送るだけで SMS を送信させる方法です。プログラミング不要でノーコード寄りに構築できます。

### 前提条件
- スマホに [Tasker](https://play.google.com/store/apps/details?id=net.dinglisch.android.taskerm)（有料アプリ）をインストール
- （推奨）Tasker 標準の HTTP サーバー機能、または連携アプリ「AutoRemote」「Join by joaomgcd」などを併用

### 設定手順（概要）
1. Tasker で新規プロファイルを作成し、トリガーを **「Event」→「Net」→「HTTP Request」**（または AutoRemote/Join の受信イベント）に設定。
2. トリガーに紐づくタスクとして **「Phone」→「Send SMS」** アクションを追加し、宛先番号とメッセージ本文を、受信した HTTP リクエストのパラメータから取得するように設定（`%http_data` などの変数を使用）。
3. スマホ側で Tasker の HTTP サーバーを起動、またはポートを指定してリッスンさせる。
4. PC から `curl` などで HTTP リクエストを送信:
   ```bash
   curl -X POST "http://<スマホのIPアドレス>:<ポート>/send_sms" \
     -d "to=090XXXXXXXX&message=Tasker経由の遠隔送信テスト"
   ```

### メリット・デメリット
- ○ ノーコードに近く、GUI で条件分岐やトリガーを柔軟に組める
- ○ IFTTT やその他 Webhook 連携とも組み合わせやすい
- × Tasker 自体が有料
- × HTTP サーバーを外部公開する場合、認証やアクセス制御を自分で作り込む必要がある

---

## 5. セキュリティ上の注意点

- **SSH や HTTP サーバーをインターネットに直接公開しない。** どうしても外出先から使いたい場合は VPN（Tailscale, WireGuard など）経由でアクセスすることを強く推奨します。
- Termux の SSH はデフォルトでパスワード認証が有効なため、公開鍵認証に切り替え、パスワード認証は無効化することを推奨します。
- SMS 送信は課金・迷惑行為につながり得る機能です。第三者に無断でスマホへのアクセス手段を渡さないでください。
- 会社支給端末の場合は、社内のセキュリティポリシー（Termux や Tasker のインストール可否、SSH ポートの利用可否）を事前に確認してください。

## 6. トラブルシューティング

| 症状 | 想定される原因 | 対処 |
|---|---|---|
| Google メッセージのウェブ版で QR コードが読み取れない | スマホのカメラ権限が無効、または QR コード画面のタイムアウト | 「メッセージ (ウェブ版)」画面を開き直し、再度 QR を表示する |
| `termux-sms-send` が「Permission denied」になる | Termux:API に SMS の権限が許可されていない | 設定 → アプリ → Termux:API → 権限 → SMS を許可 |
| SSH 接続がタイムアウトする | スマホと PC が別ネットワーク、またはスマホ側のスリープでネットワークが切断 | 同一 Wi-Fi か確認。スマホの「バッテリー最適化」対象から Termux を除外 |
| Tasker の HTTP リクエストが届かない | ポートがファイアウォールでブロック、または Tasker の HTTP サーバーが停止 | ルーター/OSのファイアウォール設定を確認し、Tasker側でサーバーが起動中か確認 |
| SMS が「送信中」のまま止まる | モバイル回線の電波が弱い、SIM未挿入、機内モード | スマホ側の電波状況・SIM状態を確認 |
