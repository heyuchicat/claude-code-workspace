# iPhone カメラアプリ (PWA)

iPhoneのSafariから使えるカメラ/ビデオ撮影アプリです。ネイティブアプリではなくWebアプリ(PWA)として作られており、HTTPS環境にホストしてSafariで開くだけで使えます。

パワハラなどのハラスメント被害の証拠を残す用途を想定し、起動時は一見ふつうのブラウザに見える画面(偽装ブラウザ画面)になっています。証拠となる音声も記録できるようマイクも合わせて使用します。**記録した写真・動画は、本人が当事者として関わるやり取りの証拠保全など正当な目的にのみ利用してください。** 第三者を無断で撮影する目的では使用しないでください。

## 主な機能

- **起動時は偽装ブラウザ画面**: 検索バーやツールバーを備えた、ふつうのWebページのような見た目で起動します
  - 住所欄を **0.8秒 長押し** すると、通常のカメラ操作画面に切り替わります
  - 住所欄右の更新アイコンをタップすると、その場でビデオ撮影を開始/停止します(住所欄の小さな赤いドットが録画中の目印)
  - カメラ操作画面の左上の矢印アイコンで、いつでも偽装ブラウザ画面に戻れます
- **写真撮影**: シャッターボタンで撮影(操作音は鳴りません。視覚的なフラッシュ演出と軽い振動のみ)
- **動画撮影**: 写真/ビデオのモード切り替えで録画。音声も同時に記録し、経過時間を表示
- 前面/背面カメラの切り替え(録画中は切り替え不可)
- 対応端末ではフラッシュ(トーチ)のON/OFF切り替え。非対応の場合は写真撮影時に画面を光らせて代用
- 撮影した写真・動画をブラウザ内(IndexedDB)に保存し、一覧・拡大再生
- 写真・動画の端末への保存(ダウンロード)・削除
- ホーム画面に追加してアプリのように起動(PWA / manifest.json、アイコン・アプリ名は一般的なブラウザ風)
- オフラインでもアプリ本体を開けるようService Workerでキャッシュ

## 使い方

1. このディレクトリを何らかのHTTPS対応の静的ホスティング(GitHub Pages, Vercel, Netlify など)にデプロイします。
   - カメラ/マイクAPI(`getUserMedia`)はセキュリティ上の理由から `https://` または `localhost` でのみ動作します。
2. iPhoneのSafariでデプロイ先のURLを開きます。
3. カメラ・マイクへのアクセスを許可します。
4. 共有ボタン →「ホーム画面に追加」で、アプリのようにアイコンから起動できるようになります(アイコン・名前は汎用的なブラウザ風です)。

## ローカルでの動作確認

```sh
cd ios-camera-app
python3 -m http.server 8080
```

`http://localhost:8080` にPCのブラウザ(Chrome/Safari)でアクセスすれば、`localhost` なのでHTTPSなしでもカメラAPIが動作します。iPhone実機で試す場合はHTTPS配信が必要です。

## ファイル構成

- `index.html` — 画面構造(カメラ操作画面 + 偽装ブラウザ画面)
- `style.css` — UIスタイル
- `app.js` — カメラ/マイク制御・写真撮影・動画録画・写真動画管理のロジック
- `manifest.json` / `sw.js` — PWA化(ホーム画面追加・オフライン対応)
- `icons/` — アプリアイコン(汎用ブラウザ風)
