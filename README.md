# claude-code-workspace

業務運用に使う社内ドキュメント・テンプレート置き場です。

## デジタルマーケティングサービス 立ち上げ資料

MEO対策・Google広告（ディスプレイ／ローカル）・META広告・HP/LP制作を組み合わせて提供するための
情報・テンプレート一式です。まずは下記のチェックリストから読んでください。

- [運用開始チェックリスト（法人版）](docs/meo-service-launch-checklist.md) — 全体像・今日やる順番
- [有料ツール比較](docs/meo-tools-comparison.md) — 有料ツールと自作代替、導入タイミング
- [ランディングページ](lp/index.html) — 自作LP（既存HPへの統合 or 無料ホスティング可）
