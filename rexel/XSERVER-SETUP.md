# エックスサーバー — 初期セットアップ（REXEL公開前の下準備）

対象: エックスサーバーを契約したばかりで中身が空、ドメインは取得済みだが
まだサーバーに紐付けていない状態。

この作業を終えてから `MIGRATION-GUIDE.md` のフェーズ2（ルートA推奨）に進みます。
契約したてで上書きの心配がないため、`MIGRATION-GUIDE.md` の「A-1. 本番サイトを
先にバックアップする」は不要です（まっさらな状態なのでスキップして構いません）。

サーバーパネルの項目名は時期により多少変わることがあります。
表記が違う場合は近い名前のメニューを探してください。

---

## 1. ドメインをサーバーに追加する

すでにお持ちのドメインを、契約したエックスサーバーに紐付けます。

1. **サーバーパネル**にログイン
   （エックスサーバーの契約完了メールに記載の「サーバーパネル」URL、
   もしくは https://www.xserver.ne.jp/login/ から）
2. 「ドメイン」→「ドメイン設定」を開く
3. 「ドメイン設定追加」タブを選び、お持ちのドメイン名を入力して追加
4. 「無料independent SSLを利用する（自動更新）」にチェックを入れて追加
   （後述のSSL設定が自動で進みます。項目が無ければ手動で3章を行う）

### お名前.com で取得したドメインをエックスサーバーに向ける

ドメインは **お名前.com** 取得とのことなので、ネームサーバーの向き先を
エックスサーバーに変更する必要があります。

1. [お名前.com Navi](https://navi.onamae.com/) にログイン
   （お名前.com の会員ID・パスワード。ドメイン取得時の登録メールに記載があります）
2. 上部メニュー「ドメイン」→「ドメイン機能一覧」を開く
3. 対象のドメイン名にチェックを入れる
4. 機能一覧の中から「ネームサーバーの変更」を選ぶ
   （「DNS」や「ネームサーバー設定」という表記の場合もあります）
5. 「他のネームサーバーを利用」を選択し、ネームサーバー1〜5に以下を入力
   ```
   ns1.xserver.jp
   ns2.xserver.jp
   ns3.xserver.jp
   ns4.xserver.jp
   ns5.xserver.jp
   ```
   （エックスサーバーのサーバーパネル「サーバー情報」に表示される値が
   これと異なる場合は、そちらを優先してください）
6. 「確認画面へ進む」→「設定する」

> **お名前.com の「ネームサーバーなしで有効化」や「AXFR用ネームサーバー」
> ではなく「他のネームサーバーを利用」を選ぶのが重要です。** 選択を誤ると
> 反映されません。

反映まで数時間〜最大72時間かかります。すぐに反映されなくても異常ではありません。

> **注意（このドメインで従来メールを使っている場合）**: ネームサーバーを
> 切り替えると、お名前.com側で設定していたメール関連のDNSレコード
> （MXレコード等）も引き継がれなくなります。このドメインで独自メール
> アドレスを運用している場合は、切り替え前にお名前.com側のDNSレコード
> 設定画面をスクリーンショット等で控えておき、切り替え後にエックスサーバー
> の「DNSレコード設定」で同じ内容を再設定してください。心当たりが無ければ
> 気にしなくて大丈夫です。

反映状況は次のコマンドで確認できます（ターミナルで）。

```bash
dig ドメイン名 NS +short
```

`ns*.xserver.jp` が表示されれば反映済みです。

## 2. WordPress をインストールする

ネームサーバーの反映を待たなくても、この作業自体は先に進められます。

1. サーバーパネル →「WordPress」→「WordPress簡単インストール」
2. 対象のドメインを選択
3. 「WordPress簡単インストール」タブで以下を入力
   - **サイトURL**: 空欄のまま（ドメイン直下に入れる場合）
   - **ブログ名**: 後で変更可能なので仮の名前でよい（例: REXEL）
   - **ユーザー名 / パスワード**: 本番管理者用の新しいものを設定
     （Studio側と同じものを使い回さない方が安全です）
   - **メールアドレス**: 通知を受け取りたいアドレス
4. 「インストール（確認）」→「インストール（確定）」

完了すると管理画面URL（`https://ドメイン/wp-admin/`）が表示されます。
**このURLとログイン情報は、この後インポートすると一時的に使えなくなります**
（`MIGRATION-GUIDE.md` の「A-4」参照）。念のため控えておいてください。

---

## 3. 独立SSL（https化）を設定する

1章の手順4でチェックを入れていれば自動で設定されるので、この章は
反映されているか確認するだけで済みます。反映されていない場合のみ手動で行います。

1. サーバーパネル →「SSL設定」
2. 対象ドメインを選択し「独立SSL設定」タブ
3. 「独立SSL設定を追加する」→ 反映まで最大1時間程度

反映後、`https://ドメイン/` でブラウザに鍵マークが出ることを確認してください。

> ネームサーバーがまだエックスサーバーに向いていない段階ではSSLの発行が
> 保留になることがあります。1章の反映を待ってから再確認してください。

---

## 4. アップロード容量の上限を上げておく（推奨）

`MIGRATION-GUIDE.md` のルートA（All-in-One WP Migration）でインポートする際、
PHPの初期設定だと容量オーバーになることがあります。先に上げておくと手戻りがありません。

1. サーバーパネル →「PHP Ver.切替」で PHP のバージョンを確認
   （最新の安定版を推奨。WordPressの推奨PHPバージョンに合わせる）
2. サーバーパネル →「php.ini設定」
3. 対象ドメインを選び、以下を編集
   ```
   upload_max_filesize = 512M
   post_max_size = 512M
   memory_limit = 256M
   max_execution_time = 300
   ```
4. 「確認画面へ進む」→保存

---

## 5. ここまで終わったら

- [ ] `dig ドメイン名 NS +short` で `ns*.xserver.jp` が表示される
- [ ] `https://ドメイン/` で鍵マーク付きで開ける
- [ ] `https://ドメイン/wp-admin/` でログインできる（初期状態のWordPressが表示される）
- [ ] php.ini のアップロード上限を上げた

すべて確認できたら、`MIGRATION-GUIDE.md` の**フェーズ2・ルートA**に進んで、
Studio側からエクスポートした `.wpress` ファイルをこの本番サイトにインポートしてください。
（インポート後にログイン情報がStudio側のものへ置き換わる点は、
`MIGRATION-GUIDE.md` の「A-4. インポート直後の必須作業」に記載しています）

## トラブル

### ドメインを追加したのに「このドメインは使用できません」と出る

他のサーバーやサービスに紐付いたままの可能性があります。
取得元のサービス側で、そのドメインが別のホスティングに使われていないか確認してください。

### SSLが「発行失敗」になる

ほとんどの場合、ネームサーバーの反映待ちです。1章の `dig` コマンドで
反映を確認してから、サーバーパネルで「独立SSL設定」を一度削除して入れ直すと直ることが多いです。

### WordPress簡単インストールでエラーになる

同じドメインに既にWordPressが入っていないか確認してください。
契約直後であれば通常は発生しません。

### お名前.com側で「ネームサーバー変更」がグレーアウトしている / 選べない

ドメインが「Whois情報公開代行」や「ドメインプロテクション」のオプションと
競合しているケースは稀にありますが、多くは単に反映処理中です。
少し時間を置いて再度お名前.com Naviにログインし直すと選べるようになります。
それでも変わらない場合は、お名前.comのサポートに問い合わせるのが確実です。
